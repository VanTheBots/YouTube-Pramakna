SIRVAN DOWNLOADER V3.1 — WINDOWS 10/11 64-BIT

PASANG SEKALI
1. Buka Microsoft Store. Cari Python 3.13.
2. Pastikan penerbitnya Python Software Foundation, lalu klik Get/Install.
3. Ekstrak ZIP ini ke folder baru. Klik dua kali INSTALL.bat.
4. Tunggu sampai selesai. Shortcut SirVan Downloader muncul di Desktop.
Jika Python Store belum tersedia, pemasang membuka pencarian Store dan berhenti.
Pasang Python dari Store, lalu jalankan INSTALL.bat kembali.

CARA PAKAI
Tempel link video TikTok (satu per baris), pilih folder, klik Download.
Bisa beberapa link sekaligus. Folder terakhir diingat dan unduhan yang sudah
tercatat di folder itu dilewati. Klik Buka folder untuk melihat hasil.

JIKA GAGAL
Klik Perbarui mesin untuk memperbarui paket yt-dlp resmi dari PyPI.
Jika gagal lagi, klik Buka log dan kirim file .log terbaru atau screenshot.
Video privat/dihapus, pembatasan TikTok, atau kebijakan Windows bisa menghalangi.
Jangan menonaktifkan Smart App Control atau antivirus untuk menjalankan aplikasi.

PERUBAHAN V3
Menggunakan Python 3.13 distribusi Microsoft Store yang sudah dipasang pengguna.
Tidak mengunduh atau menjalankan pemasang Python .exe yang gagal pada versi 2.
Tidak menjalankan yt-dlp.exe yang diblokir pada versi 1.
Tidak mengubah kebijakan keamanan Windows. TLS tetap diverifikasi.
Paket yt-dlp dipasang dalam lingkungan aplikasi venv-store, terpisah dari Python utama.

KUALITAS
Memilih MP4 audio+video terbaik yang tersedia, atau file gabungan terbaik
jika MP4 tidak tersedia. Tidak melakukan kompresi ulang atau menaikkan resolusi.
Versi tanpa watermark bergantung pada sumber yang tersedia. Watermark yang
sudah menyatu dalam sumber tidak dihapus. FFmpeg tidak diperlukan untuk alur ini.

LOKASI & PENGHAPUSAN
Program: %LOCALAPPDATA%/SirVanDownloader
Tutup aplikasi lalu hapus folder program dan shortcut Desktop untuk menghapus.
Footage tetap tersimpan di folder pilihanmu. Python Store dapat dihapus terpisah
melalui Settings > Apps jika tidak dipakai aplikasi lain.

BATAS PENGUJIAN
Sintaks PowerShell dan worker dengan mesin simulasi diperiksa di Linux.
Jalur paket Python yt-dlp diuji di Linux. Instalasi Microsoft Store, virtual
environment Store, antarmuka Windows, dan unduhan TikTok di laptop belum diuji.
Keberhasilan pada Smart App Control belum dapat dijamin.

PEMBARUAN 3.1
Mesin memakai yt-dlp nightly beserta dependensi default dan curl_cffi.
Pengguna versi 3 cukup menjalankan PERBAIKI.bat untuk memperbarui.
