# SirVan Downloader untuk Windows

[Unduh SirVan Downloader (ZIP)](https://github.com/VanTheBots/YouTube-Pramakna/raw/refs/heads/sirvan-downloader-windows/downloads/SirVan-Downloader-Windows.zip)

1. Unduh ZIP, lalu klik kanan **Extract All / Ekstrak Semua**.
2. Buka folder hasil ekstrak, lalu klik dua kali **INSTALL.bat**.
3. Tunggu pemasangan selesai. Shortcut **SirVan Downloader** muncul di Desktop.
4. Tempel link video TikTok, pilih folder, lalu klik **Download**.

Memerlukan Windows 10/11 64-bit dan koneksi internet. Tidak memerlukan langganan atau Python. Mesin yt-dlp diunduh dari repositori resminya dan diverifikasi dengan SHA256 saat pemasangan/pembaruan.

Aplikasi mendukung beberapa link, mengingat folder terakhir, melewati unduhan yang telah tercatat, dan menyediakan tombol pembaruan serta log. Kualitas mengikuti file gabungan terbaik yang tersedia; watermark yang sudah menyatu dalam sumber tidak dihapus.

Sintaks PowerShell dan alur sukses/gagal worker dengan pengunduh simulasi telah diuji di Linux. Antarmuka Windows, pemasangan end-to-end, dan unduhan TikTok nyata belum diuji. Akses TikTok dapat berubah. Jika Windows memblokir pemasang, jangan mematikan antivirus; kirim pesan kesalahannya untuk diperiksa.
